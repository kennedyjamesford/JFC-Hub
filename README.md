# JFC Hub

A standalone, responsive operations hub for James Ford Construction.

## Run locally

Open `index.html` in a modern browser. No server, build step, external dependency, or account is required.

The app includes a profile selector for 14 team members, clocking, weekly timesheets, job/site overviews, site-photo logging, plant checks and defect reporting, document/RAMS library, daily reports, management/job-costing view, plant status and social content planner. Interactions are client-side and demo entries persist only in `localStorage`.

The supplied `assets/jfc-logo.png` is the official logo from the James Ford Construction website.
